Core Features

Enterprise-Grade Architecture

Every component is precision-engineered for accuracy, speed, and reliability in live market conditions.

Unified Scoring Engine

8 core + 8 bonus scoring factors merged into a single score from -20 to +20. Includes Structure, EMA, Volume, Squeeze, Daily Trend, Session, AVWAP, and Candle Patterns.

9-Factor Confluence

Dynamic confluence filter requires multiple confirmations before any signal. Automatically adjusts thresholds based on the current market regime.

Market Regime Detection

Real-time identification of Trending, Ranging, Volatile, or Transitioning markets using ADX + ATR ratio. Adapts TP/SL/position sizing automatically.

Wyckoff Effort vs Result

Detects absorption and distribution events by comparing volume effort to price result. Extreme volume + weak body = institutional distribution signal.

Virtual Order Flow

Wick-analysis-based order flow inference. Tracks institutional buying/selling pressure through a 50-bar rolling average of buy/sell absorption bars.

Risk Manager V1

Dynamic ATR-based Stop Loss, 3 Take Profit targets, regime-adjusted position sizing, and built-in gap-down protection for the Egyptian market.

★ Portfolio Risk Tool

Standalone HTML companion tool for multi-stock portfolio heat tracking, sector correlation matrix, position sizing calculator, and real-time worst-case scenario analysis. Works offline — no server needed.

★ Risk Manager V2

10 advanced tools: Portfolio Heat, Circuit Breaker, Correlation Guard, Kelly Criterion, Smart Entry Zones, Volatility-Adjusted Exits, Expectancy Calculator, and more.

Scanner

20-Symbol Real-Time Scanner

Scans 20 Shariah-compliant EGX stocks simultaneously using the exact same V1 algorithm with 40 explicit request.security calls.

Signal Grading (A+ → D)

Every stock receives a letter grade based on score + confluence intersection. A+ requires Score ≥7 and Confluence ≥4.

Auto Sort by Score

Dashboard automatically ranks all 20 stocks from highest to lowest score. Best opportunities always at the top.

Market Breadth

Real-time aggregate view: bullish/bearish/neutral stock count, average score, and overall market sentiment (Risk ON/OFF).

Companion Tool

Portfolio Risk Manager

A standalone HTML tool that solves Pine Script's limitation of not tracking positions across multiple stocks — bridging the gap between CMD's per-stock analysis and your total portfolio risk.

Portfolio Heat Map

Add all open trades with entry price, stop loss, and shares. See your total portfolio risk as a visual gauge — matches CMD's built-in "Open Trades Count" input.

Auto Position Sizing

Enter your capital and risk budget → get the exact maximum shares for any trade. Integrates with CMD's ATR-based stop loss for precise calculations.

Sector Correlation Matrix

Visualizes correlation between EGX stocks by sector. Prevents overexposure to the same market direction — complements CMD's Correlation Guard.

Worst-Case Analysis

Calculates the maximum portfolio drawdown if all stops hit simultaneously. JSON import/export for data persistence. Copy-to-clipboard for quick sharing.
